# Failure drills: อะไรพังได้ในวันงาน และทำอะไรใน 5 นาทีแรก

ใช้ร่วมกับ [deployment.md](deployment.md) (Render, Railway, rollback, dump) และ [environments.md](environments.md) (Neon, WSL, tunnel) · [prompts/README.md](../../prompts/README.md) (prompt 7 = เริ่มเซสชัน worker ใหม่, prompt 10 = orchestrator chat ใหม่) · กติกา: โพสต์บนบอร์ดผ่าน `tools/team-board.ps1` เท่านั้น · ห้ามใส่ key/token ในโพสต์

อ่านแถวเดียวที่ตรงอาการ: **สังเกตอย่างไร → ตอบสนอง ≤ 5 นาที → สำรอง** · ผู้รับผิดชอบหลักในวงเล็บ

## 2. ใครตัดสินใจ

| เรื่อง | ผู้ตัดสิน |
|---|---|
| สลับ Render → Railway, ย้อน deploy | C (ที่ถือบัญชี) + C0 · แจ้งหัวหน้า |
| เพิ่มวงเงิน OpenAI, สลับ key | หัวหน้า |
| merge โดยไม่รอ CI | หัวหน้าเท่านั้น |
| ซ่อนฟีเจอร์เพราะ provider ล้ม | orchestrator ของเจ้าของ + C (กด flag ที่ `/ops`) |
| ใช้ fallback เครื่องเบา (ยุบ lane 3) | หัวหน้า |

ทุกการตัดสินใจโพสต์บนบอร์ดหนึ่งบรรทัด (อะไร, ใคร, เวลา) เพื่อให้ทุก orchestrator เห็นตรงกัน
